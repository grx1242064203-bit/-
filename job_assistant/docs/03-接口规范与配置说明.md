### 1.3 配置加载机制

`main.py` 和 `verify_fix.py` 顶部有统一的 `.env` 加载逻辑（不依赖 `python-dotenv`）：

```python
_env_path = os.path.join(os.path.dirname(os.path.abspath(__file__)), ".env")
if os.path.exists(_env_path):
    with open(_env_path, "r", encoding="utf-8") as _f:
        for _line in _f:
            _line = _line.strip()
            if not _line or _line.startswith("#") or "=" not in _line:
                continue
            _k, _v = _line.split("=", 1)
            _k = _k.strip()
            _v = _v.strip().strip('"').strip("'")
            if _k and _k not in os.environ:
                os.environ[_k] = _v
```

**注意**：`os.environ` 中已存在的变量不会被 `.env` 覆盖（`if _k not in os.environ`）。

## 2. 飞书 API 接口规范

### 2.1 认证

- 使用 `tenant_access_token`（应用身份），非用户 token
- 获取接口：`POST /open-apis/auth/v3/tenant_access_token/internal`
- 有效期：2 小时，提前 5 分钟刷新
- 请求头：`Authorization: Bearer {token}`

### 2.2 核心 API 列表

| 功能 | 方法 | 路径 |
|------|------|------|
| 获取 tenant token | POST | `/open-apis/auth/v3/tenant_access_token/internal` |
| 创建多维表格 | POST | `/open-apis/bitable/v1/apps` |
| 列出数据表 | GET | `/open-apis/bitable/v1/apps/{app_token}/tables` |
| 创建数据表 | POST | `/open-apis/bitable/v1/apps/{app_token}/tables` |
| 创建字段 | POST | `/open-apis/bitable/v1/apps/{app_token}/tables/{table_id}/fields` |
| 批量创建记录 | POST | `/open-apis/bitable/v1/apps/{app_token}/tables/{table_id}/records/batch_create` |
| 搜索记录 | GET | `/open-apis/bitable/v1/apps/{app_token}/tables/{table_id}/records/search` |
| 删除记录 | DELETE | `/open-apis/bitable/v1/apps/{app_token}/tables/{table_id}/records/{record_id}` |
| 获取单条记录 | GET | `/open-apis/bitable/v1/apps/{app_token}/tables/{table_id}/records/{record_id}` |
| 创建文档 | POST | `/open-apis/docx/v1/documents` |
| 追加文档块 | POST | `/open-apis/docx/v1/documents/{doc_id}/blocks/{block_id}/children` |
| 分享资源 | POST | `/open-apis/drive/v1/permissions/{token}/members?type={doc_type}` |
| 转移所有权 | POST | `/open-apis/drive/v1/permissions/{token}/members/transfer_owner?type={doc_type}` |
| 解析 wiki 节点 | GET | `/open-apis/wiki/v2/spaces/get_node?token={token}` |

### 2.3 重要错误码

| code | 含义 | 处理方式 |
|------|------|----------|
| 0 | 成功 | - |
| 91402 | NOTEXIST（token 不存在） | 可能是 wiki node_token，需调用 `get_node` 解析为 obj_token |
| 99991400 | 限流 | 指数退避重试 |
| 1254291 | 临时错误 | 重试 |
| 500 | 服务端错误 | 重试 |

### 2.4 字段类型映射

| 飞书 type | 常量 | 说明 |
|-----------|------|------|
| 1 | FIELD_TYPE_TEXT | 文本 |
| 2 | FIELD_TYPE_NUMBER | 数字 |
| 3 | FIELD_TYPE_SELECT | 单选/多选 |
| 5 | FIELD_TYPE_DATETIME | 日期 |
| 15 | FIELD_TYPE_URL | 超链接 |

### 2.5 字段读写格式差异

| 类型 | 写入格式 | 读出格式 |
|------|----------|----------|
| select | `"选项名"` 或 `["选项1","选项2"]` | `[{"name": "选项名"}]` |
| url | `{"text": "...", "link": "..."}` | `{"text": "...", "link": "..."}` |
| datetime | `"yyyy-MM-dd HH:mm:ss"` 或时间戳 | 时间戳（毫秒） |

`normalize_fields()` 方法负责将读出格式归一化为可写入格式。

## 3. WxPusher API 接口规范

### 3.1 基础信息

- API 地址：`https://wxpusher.zjiecode.com/api`
- 认证：`appToken`（请求体中传递）

### 3.2 核心接口

| 功能 | 方法 | 路径 |
|------|------|------|
| 获取关注二维码 | POST | `/fun/create/qrcode` |
| 发送消息 | POST | `/send/message` |

### 3.3 发送消息请求体

```json
{
  "appToken": "AT_xxx",
  "content": "Markdown 内容",
  "contentType": 3,        // 1=文本 2=HTML 3=Markdown
  "uids": ["UID_xxx"],
  "url": "https://..."     // 可选，点击跳转链接
}
```

## 4. 搜索 API 接口规范

### 4.1 Tavily

- 地址：`POST https://api.tavily.com/search`
- 请求体：`{api_key, query, search_depth, max_results, include_answer}`
- 响应：`results` 数组，每项含 `title`, `url`, `content`

### 4.2 SerpAPI

- 地址：`GET https://serpapi.com/search`
- 参数：`q, api_key, num, engine=google, hl=zh-cn`
- 响应：`organic_results` 数组，每项含 `title`, `link`, `snippet`

## 5. 飞书事件回调规范

### 5.1 回调端点

- URL：`https://zhaopin-helper.xyz/feishu/callback`
- 方法：POST
- Content-Type：application/json

### 5.2 事件结构（v2.0）

```json
{
  "header": {
    "event_id": "...",
    "event_type": "app_open",
    "tenant_key": "...",
    "create_time": "..."
  },
  "event": {
    "sender": {
      "sender_id": {
        "open_id": "ou_xxx"
      }
    }
  }
}
```

### 5.3 URL 验证

飞书配置回调地址时会发送 challenge：

```json
{ "challenge": "xxx" }
```

响应：`{ "challenge": "xxx" }`

### 5.4 订阅事件

| 事件类型 | 触发时机 |
|----------|----------|
| `app_open` | 用户打开应用 |
| `app_install` | 用户安装应用 |
