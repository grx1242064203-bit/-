# 06. 测试策略与质量保障

## 1. 测试策略概览

本项目 MVP 阶段以**手动验证 + 脚本验证**为主，不强制单元测试。但核心逻辑（评分、去重、token 解析）应具备可测试性。

| 层级 | 方式 | 覆盖范围 |
|------|------|----------|
| 语法检查 | `py_compile` | 所有 .py 文件 |
| 模块验证 | `verify_fix.py` | 凭证、token 解析、每日任务 |
| 手动测试 | 飞书端到端 | onboarding、写入、推送 |
| 生产验证 | 健康检查 + 日志 | 服务可用性 |

## 3. 核心逻辑验证

### 3.1 评分引擎验证

```python
# 验证评分逻辑可解释
from scorer import score_job, _make_hash
from models import UserProfile

profile = UserProfile(
    major="计算机",
    degree="本科",
    core_skills=["Python", "SQL"],
    direction_keywords={"产品经理": ["pm", "产品"]},
    target_cities=["北京"],
)

job = {
    "title": "字节跳动 产品经理 校招",
    "company": "字节跳动",
    "jd_text": "要求：本科及以上，Python优先，SQL熟练，应届毕业生",
    "location": "北京",
    "salary": "20-30K",
    "jd_url": "https://example.com/job/123",
    "jd_summary": "...",
    "crawl_date": "2026-09-26",
    "posted": "2026-09-20",
}

result = score_job(job, profile)
assert result["相关性评分"] > 50
assert result["综合推荐度"] in ["优先申请", "可申请"]
assert result["去重hash"] == _make_hash("字节跳动", "字节跳动 产品经理 校招", "北京", "https://example.com/job/123")
print("评分验证通过")
```

### 3.2 去重 hash 验证

```python
from scorer import _make_hash

# 同公司同岗位同城市同链接 → 相同 hash
h1 = _make_hash("字节", "产品经理", "北京", "https://example.com/1")
h2 = _make_hash("字节", "产品经理", "北京", "https://example.com/1")
assert h1 == h2

# 不同链接 → 不同 hash
h3 = _make_hash("字节", "产品经理", "北京", "https://example.com/2")
assert h1 != h3
print("去重 hash 验证通过")
```

## 6. 质量保障红线

以下问题**禁止**合并到生产分支：

1. **语法错误**：`py_compile` 不通过
2. **硬编码密钥**：代码中出现真实的 app_secret / api_key
3. **静默吞异常**：`except Exception: pass` 无日志
4. **丢失用户数据**：未持锁写 users.json
5. **破坏 onboarding**：新用户无法创建多维表格
