## 2026-09-25 — 91402 NOTEXIST 修复

**问题**：飞书 API 返回 `code=91402 NOTEXIST`

**根因**：用户多维表格挂在知识库(wiki)下，存储的 `base_token` 是 wiki node_token，直接用于 bitable API 会报错。

**修复**：
- `feishu_client.py` 新增 `resolve_app_token()` 方法
- 所有 bitable/drive API 调用前先解析 wiki node_token → obj_token
- `onboarding.py` 新增 `migrate_user_tokens()` 迁移存量用户

**影响**：所有涉及飞书 API 调用的模块

---

## 2026-09-24 — KeyError: 'url' 修复

**问题**：`create_doc()` 中 `data["url"]` 抛 KeyError

**根因**：飞书 docx API 响应不含 `url` 字段

**修复**：手动拼接 URL `f"https://{domain}/docx/{doc_id}"`，domain 从 `FEISHU_DOMAIN` 环境变量读取

## 2026-09-23 — Onboarding 竞态条件修复

**问题**：并发回调创建多个多维表格

**根因**：缺少并发控制

**修复**：`onboarding.py` 添加 `_onboarding_lock = threading.Lock()`，加锁后双重检查用户存在性
