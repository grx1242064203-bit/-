# 招聘情报助手 — 客户使用手册

> 本手册面向已付费客户，指导您完成从安装到日常使用的全流程。

---

## 一、产品简介

**招聘情报助手**是一款"AI 替你每天筛岗位"的工具。

> **校招用户特别说明**：校招岗位由系统统一中心化采集（覆盖 488 家 2024-2026 发过校招公告的企业），存入总数据库后按您的求职偏好匹配分发。您无需关心采集过程，每天直接收到匹配好的岗位。

每天早上 9 点，系统会自动：
1. 🔍 **匹配岗位**：从总数据库中筛选与您求职方向匹配的校招岗位（校招用户）/ 全网搜索匹配岗位（社招用户）
2. 🎯 **AI 评分**：根据您的专业、技能、目标公司/城市，对每个岗位打分
3. 📊 **写入飞书**：将岗位自动录入您专属的飞书多维表格
4. 📄 **生成日报**：创建一份飞书文档，汇总当日精选岗位
5. 💬 **飞书推送**：通过飞书消息向您发送当日岗位摘要卡片

您只需要：**安装飞书应用 + 配置求职偏好**，之后每天自动收到推送。

---

## 二、首次使用完整步骤

### 第一步：安装飞书应用

1. 打开飞书 App（手机或电脑端均可）
2. 点击管理员发送的**应用安装链接**
3. 点击「获取」或「安装」
4. 安装完成后，**打开应用一次**（触发自动创建您的专属岗位库）

✅ 完成后，您的飞书云空间中会自动出现一个名为 **「招聘情报库」** 的多维表格。
同时您会收到一条飞书消息，内含求职偏好配置链接。

> ⚠️ 重要：安装后请**打开应用一次**，否则系统无法为您创建岗位库。

---

### 第二步：配置求职偏好（自助页面）

点击飞书消息中的配置链接，打开「个人配置」页面：

1. **选择求职角色**：校招 / 社招（决定采集岗位类型，实习功能已下线）
2. **（可选）简历智能解析**：粘贴简历文本，点击「AI 解析简历」，系统自动提取学校、学历、专业、技能等信息
3. **填写目标岗位方向**：可添加多个方向，每个方向填 2-3 个关键词（如：产品经理 → 产品, PM）
4. **填写其他信息**：专业、学历、工作年限、核心技能、目标公司、目标城市
5. **校招用户额外配置**：偏好公司类型（国央企/民企/外企）、可接受难度、是否偏好管培项目
6. **点击「保存偏好配置」**

✅ 保存后系统会立即为您采集第一批岗位，采集完成后通过飞书消息通知您结果。

---

### 第三步：验证服务正常

保存偏好后，您应该能看到：

1. **飞书多维表格**「招聘情报库」中出现岗位记录
2. 收到一条 **飞书消息**，包含采集结果摘要和岗位库链接

如果保存后 30 分钟内未收到任何消息，请联系管理员检查。

## 三、日常使用

### 3.1 查看岗位库（飞书多维表格）

打开飞书 → 云空间 → 「招聘情报库」多维表格。

表格包含 **「岗位数据库」** 和 **「已关闭岗位」** 两张表（校招用户额外有 **「管培生项目」** 表）：

#### 岗位数据库（在招岗位）

| 字段 | 说明 |
|------|------|
| 岗位标题 | 岗位名称 |
| 公司 | 招聘公司 |
| **行业** | 公司所属行业（来自总数据库） |
| **公司类型** | 国央企 / 民企 / 外企 |
| **申请难度** | 最激烈 / 激烈 / 普通 / 轻松 |
| 部门 | 招聘部门 |
| 地点 | 工作城市 |
| 薪资范围 | 薪资（如"20-30K"） |
| 经验要求 | 要求工作年限 |
| 学历要求 | 要求学历 |
| JD摘要 | 岗位描述 AI 摘要 |
| JD链接 | 点击查看完整 JD |
| 抓取日期 | AI 采集到该岗位的日期 |
| **发布时间** | 岗位公告发布时间 |
| 投递截止日期 | 校招截止日期（系统会在截止前 3 天提醒） |
| 岗位类别 | AI 归类（与您的目标方向对应） |
| 相关性评分 | 0-100 分，越高越匹配 |
| 难度评分 | 岗位难度评估 |
| 综合推荐度 | **优先申请 / 可申请 / 观望 / 跳过** |
| 简评 | AI 对岗位的简短评价 |
| 申请建议 | AI 给出的申请建议 |
| 申请状态 | 您可手动更新：未投递/已投递/面试中/Offer/拒绝 |

#### 已关闭岗位

岗位关闭（不再招聘）后，会自动从「岗位数据库」移到此处，保留历史记录。

---

### 3.2 每日推送（飞书消息）

每天早上约 9:00，您会收到一条飞书消息卡片，内容包括：

- 📅 当日日期
- 📊 新增岗位数量
- 🔥 TOP 3 推荐岗位（含公司、岗位、地点、评分）
- 🔗 岗位数据库链接（点击直达多维表格）
- 🔗 完整日报文档链接（点击查看完整岗位详情）

---

### 3.3 每日日报（飞书文档）

点击推送中的日报链接，打开飞书文档，包含：

- 当日新增岗位概览
- 优先申请岗位列表（含评分和建议）
- 关闭岗位统计
- 完整岗位库链接

---

### 3.4 如何筛选岗位

在飞书多维表格中，您可以：

1. **按综合推荐度筛选**：只看「优先申请」的岗位
2. **按相关性评分排序**：从高到低排列
3. **按岗位类别筛选**：只看您感兴趣的方向
4. **按城市筛选**：只看目标城市
5. **更新申请状态**：投递后手动改为「已投递」

## 四、评分规则说明

AI 从以下维度为每个岗位打分（满分约 110 分）：

| 维度 | 分值 | 说明 |
|------|------|------|
| 方向匹配 | 10-40 | JD 是否命中您的目标方向关键词 |
| 公司匹配 | 10-20 | 是否是您的目标公司 |
| 经验匹配 | 5-15 | JD 经验要求与您的工作年限匹配度 |
| 技能匹配 | 0-15 | 您的核心技能在 JD 中出现的数量 |
| 学历匹配 | 3-10 | JD 学历要求与您的学历匹配度 |
| 城市匹配 | 0-10 | 是否在您的目标城市 |

**综合推荐度**：
- **优先申请**（≥70分）：高度匹配，建议尽快投递
- **可申请**（50-69分）：较为匹配，可以投递
- **观望**（30-49分）：部分匹配，可作为备选
- **跳过**（<30分）：匹配度低，不建议投递

## 五、常见问题（FAQ）

### Q1：安装后为什么没有收到岗位推送？
A：请确认：① 已打开应用一次（触发创建岗位库）；② 已在配置页面填写求职偏好并保存。两者都完成后，系统会立即采集，次日 9:00 起每天推送。

### Q2：为什么推送的岗位和我想找的不太匹配？
A：请检查您填写的**目标岗位方向**和**关键词**是否准确。方向关键词越具体，匹配越精准。您可以重新打开配置页面修改偏好，保存后立即生效。

### Q3：岗位库中的「申请状态」怎么用？
A：您可以手动更新每个岗位的申请状态（未投递→已投递→面试中→Offer/拒绝），方便追踪求职进度。系统不会自动修改此字段。

### Q4：某个岗位已经关闭了，为什么还在岗位数据库里？
A：系统每天会复查在招岗位，已关闭的会自动移到「已关闭岗位」表。如果某个岗位确认已关闭但还在，可能是 JD 页面仍可访问，次日会自动归档。

### Q5：可以修改我的求职偏好吗？
A：可以。重新打开配置页面（飞书消息中的链接），修改后点击保存即可，下次采集立即生效。

### Q6：每天会推送多少个岗位？
A：系统每天最多采集 20 个与您匹配的岗位（可根据套餐调整），但只写入**新增**的岗位（已存在的不会重复推送）。

### Q7：服务到期后数据还在吗？
A：服务到期后，系统不再为您采集新岗位，但您的飞书多维表格和历史数据保留，您仍可查看。
