> 所有开发、部署、运维、问题排查均以本目录文档为准。

## 阅读顺序建议

- **第一次接触项目**：01 → 02 → 03
- **开始开发**：04 → 06
- **上线部署**：05
- **遇到问题**：08 → 10
- **了解历史**：07 → 09

## 文档维护规范

1. 每次提交代码若涉及架构、接口、配置变更，**必须**同步更新对应文档
2. 文档更新与代码变更在同一个 PR 中提交
3. 开发日志（07）按时间倒序记录，每次发版或重要修复后追加
4. 问题记录（08）采用"问题 → 根因 → 解决方案 → 预防措施"四段式
5. 架构决策（09）采用 ADR 标准格式，记录决策背景、选项、结论、后果
